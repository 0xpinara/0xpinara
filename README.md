## Pınar Aksoy

Computer engineering. I work on the empirical evaluation of machine learning
and quantitative methods — mostly on whether a reported result is real, and
what it takes to check.

### Selected work

**[guided-research](https://github.com/0xpinara/guided-research)** — Do
option-market metrics predict short-horizon stock returns? Walk-forward
evaluation with multiple-testing corrections, a volatility positive control,
and a power analysis done before the fact rather than after. First-author
manuscript under review at *Financial Innovation*.

**[benchmark-zoo](https://github.com/0xpinara/benchmark-zoo)** —
Multiple-testing corrections with a null distribution you measure instead of
assume, checked against ground truth on roughly 19,000 long–short strategies.

**[AegisQ](https://github.com/0xpinara/AegisQ)** — Distributed quantum
state-vector simulator in C++20 and MPI. Communication-aware qubit placement
removed 87.2% of measured MPI traffic on QFT. The wall-time claims are held
against a null built by re-running identical configurations, because the same
config twice varies by up to 32% with nothing changed.

**[Deep-American-Option-Pricing](https://github.com/0xpinara/Deep-American-Option-Pricing)**
— Longstaff–Schwartz against LSTM and Deep Optimal Stopping for American
options, benchmarked on binomial trees with convergence analysis.

**[PROJECT-NORTHSTAR](https://github.com/0xpinara/PROJECT-NORTHSTAR)** — A
dispute-handling platform for a simulated US retail bank. The bank is
invented and the README says so; the throughput and cost numbers come from
running the code.

**[VeritasLedger](https://github.com/0xpinara/VeritasLedger-ZK-Proof-Protocol)**
— zk-SNARK verified model inference on Base. The Circom circuits and Solidity
verifier are implemented; the photonic accelerator is a simulation, and the
README marks which numbers are modelled rather than measured.

### Interests

Evaluation methodology, multiple testing, recommendation and retrieval, and
the general problem of telling a real improvement from a well-searched one.
